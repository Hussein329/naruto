Build log

The 21-day build & launch schedule

1.5–3 hours a day. Buffer days on 7 and 14. Everything live by day 21. Sequence-dependent, not clock-dependent.

  1. D1
    Build Tier A core. Habit database and the 7-day checklist.
  2. D2
    Finish Tier A styling. Weekly summary view, then duplicate-test it.
  3. D3
    List Tier A. Write the listing, mock a thumbnail, publish to Etsy/Gumroad/Notion marketplace.
  4. D4
    Start Tier B. Daily Log tab and checkbox habit columns.
  5. D5
    Build the Dashboard. Line chart plus bar chart.
  6. D6
    Correlation section. Mood/energy vs. completion, plus category tagging.
  7. D7
    Buffer day. Catch up on overflow, answer early Tier A buyer questions.
  1. D8
    Monthly Review tab. Auto-pull formulas for top/bottom habits.
  2. D9
    Full styling pass. Colours, fonts, protect the formula cells.
  3. D10
    QA and launch Tier B. Fresh duplicate test, fix breakages, publish the listing.
  4. D11
    Tier C foundations. Character Sheet and Daily Quests database.
  5. D12
    XP system. XP rollup, Level formula, progress bar.
  6. D13
    Goal Map. Relations and rollups linking quests → milestones → Boss Goals.
  7. D14
    Buffer day.
  1. D15
    Time-Block Planner. Calendar/timeline view for habit time slots.
  2. D16
    Icon pack. Source or design it, apply across the Tier C dashboard.
  3. D17
    Badge gallery. XP-threshold reveal logic.
  4. D18
    Write the guidebook. Or script the walkthrough video.
  5. D19
    Finish the guide or video. Export as PDF or upload.
  6. D20
    Full QA pass. Fresh duplicate test — click every link, relation, and rollup.
  7. D21
    Launch. Write the Tier C listing, publish, cross-link all three tiers for upsells.

After launch — the daily 15–30 min routine

  • Same-day support. Answer buyer questions the day they come in.
  • Follow the sales. Whichever tier sells best, double down there next.
  • Weekly review. Read reviews once a week, log feature requests for v2.
Lab protocol

What's rationed, and what never is

✕ Do not over-invest

  • No real animated app for Tier C — Notion and good formulas already reads as "gamified."
  • No hand-built Excel version of Tier B until Tier A proves people are buying.
  • No skipping the fresh-duplicate test — it's the number one source of refund requests.

✓ Non-negotiable, every tier

  • Duplicated into a blank workspace and clicked through, end to end.
  • One consistent visual identity, not a grab-bag of colours.
  • A delivery mechanism that works the moment a buyer clicks it.
